Scoring conventions used:

- Accepted phrasings were treated as examples. Credit 1 needed the target meaning, in any wording.
- If the free description committed to the target reading, alternatives listed in the unsure section did not lower the score. A score of 0.5 was given when the describer never committed ('perhaps', 'not clear whose it was') or got only part of the action or object right.
- When a misread object made an inference impossible (for example, ice cream not recognised, so no 'dropped it'), the object item was scored misread and the inference 0.
- For contradiction 'notice' items, flagging the right object as odd earned 1 even if the stated reason was wrong (pic_12 i02). Flagging only a neighbouring oddity earned 0.5 (pic_03 i05).
